# KIRARI serial helper Web

シンデレラガールズ総選挙のシリアルコードを、iPhone・iPadなどのブラウザで撮影して読み取るための非公式Web補助ツールです。

## 機能

- 写真を撮る／選ぶ
- ブラウザ内で文字認識
- 16文字の英数字候補を表示
- 読み取り結果を手修正
- コピー
- 公式入力ページを開く

## プライバシー

- 撮影画像と読み取り処理は端末のブラウザ内で行います
- 写真やシリアルコードを外部サーバーへ送信しません
- 履歴は保存しません
- OCRライブラリと文字認識データはCDNから読み込みます

## 注意

- 非公式のファンメイドツールです
- 公式・関係各社とは関係ありません
- 自動入力・自動送信は行いません
- 読み取り結果は使用前に必ずご自身で確認してください

## 公開方法

GitHub Pagesで `main` ブランチの `/(root)` を公開します。
