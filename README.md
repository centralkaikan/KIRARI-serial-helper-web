# KIRARI serial helper Web

シンデレラガールズ総選挙のシリアルコードを、iPhone・iPadなどのブラウザで撮影して読み取るための非公式Web補助ツールです。

## 機能

- 写真を撮る／選ぶ
- ブラウザ内で文字認識
- 16文字のシリアル候補を抽出
- 読み取り結果の編集
- 複数の履歴をブラウザ内へ保存
- 個別コピー・公式入力ページを開く
- 個別削除・全履歴削除

## プライバシー

写真と読み取り結果は、利用中の端末・ブラウザ内で処理・保存します。写真やシリアルコードを外部サーバーへ送信しません。

OCRプログラムと英語文字データは、初回利用時にCDNから読み込みます。

ブラウザのWebサイトデータを削除すると履歴も消えます。プライベートブラウズでは保存が安定しない場合があります。

## 注意

- 非公式のファンメイドツールです
- 公式・関係各社とは関係ありません
- 自動入力・自動送信は行いません
- 読み取り結果は使用前に必ず確認してください
